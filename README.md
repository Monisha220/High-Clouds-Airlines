# ✈️ High Clouds Airlines Data Analysis Project

---

## 📌 Overview

An end-to-end data analysis project on the High Clouds Airlines dataset using Excel, MySQL, Power BI, and Tableau to analyze airline performance, passenger trends, load factor, routes, and travel patterns.

---

## 🛠️ Tools Used

- Microsoft Excel
- MySQL
- Power BI
- Tableau
